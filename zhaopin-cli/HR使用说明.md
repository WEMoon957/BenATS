# 智联招聘助手（zhaopin-cli）使用说明

## 文档信息

| 项目 | 内容 |
| --- | --- |
| 适用对象 | 人力资源部门使用人员 |
| 工具名称 | 智联招聘助手（zhaopin-cli） |
| 适用版本 | 0.1.0 |
| 最后更新 | 2026-09-30 |

## 一、工具说明

智联招聘助手用于在智联招聘企业端执行候选人查看、打招呼、索要简历等操作。系统由两个部分构成，均安装在使用人员本机：

| 组成部分 | 说明 | 提供方 |
| --- | --- | --- |
| AI 助手（WorkBuddy） | 使用人员唯一的操作界面，接收自然语言指令并代为执行 | 由公司统一提供，必须安装 |
| 智联招聘助手（zhaopin-cli） | 后台执行工具，由 AI 助手调用，使用人员无需直接操作 | 公开组件，安装时由 AI 助手自行获取 |

运行方式：

1. 工具在使用人员本机启动一个独立浏览器窗口，连接智联招聘企业端；
2. 使用人员以自然语言向 AI 助手提出需求，由助手代为完成页面操作；
3. 工具不代填任何账号信息，登录须由使用人员本人完成；
4. 所有对外发送的消息（打招呼、索要简历）均须经使用人员确认后发出。

页面操作全部通过真实鼠标点击、键盘输入与滚轮完成，不向页面注入代码，不修改智联招聘页面的任何内容。

## 二、前置条件

1. 本机已安装 Chrome 或 Edge 浏览器。浏览器一般随系统自带；如无，安装 Google Chrome 即可，无需登录浏览器账号。
2. AI 助手（WorkBuddy）已安装并完成登录。后续所有操作均通过该助手完成。

> Node.js 运行环境无需使用人员处理。工具依赖该环境运行，但由 AI 助手自带的运行环境提供，安装指令中已包含相应处理，使用人员无需安装或检查。

## 三、安装（仅需一次）

打开 AI 助手，将以下指令完整发送，等待其自动完成安装：

```text
帮我在这台电脑上装好「智联招聘助手」（zhaopin-cli），装完你就能直接用它替我操作
智联招聘企业端。我是 HR，不会敲命令，整个过程请你独立完成，不要让我执行任何命令。

请按顺序做，中间遇到问题自己判断处理：

1. 用你自己的 Node 运行环境，不要让我另外装 Node。
2. 全局安装 npm 包 @wemoon/zhaopin-cli@latest。
   如果 npm 提示 404（说明这个包还没发布到 npm），改用源码方式：
   下载 https://github.com/WEMoon957/BenATS 的 zip 并解压，
   把里面的 zhaopin-cli 文件夹放到一个固定位置，
   在你的运行环境里执行 npm install，再执行 npm install -g . 把它注册成命令。
   网络慢或超时就改用国内镜像源 https://registry.npmmirror.com 重试。
3. 自己验证一遍：先确认你能直接调用 zhaopin（例如执行 zhaopin help）；
   再跑一次自检脚本，逐项看有没有失败：
   npm 包内路径是 "$(npm root -g)/@wemoon/zhaopin-cli/scripts/self-check.mjs"，
   源码方式则是那个 zhaopin-cli 文件夹下的 scripts/self-check.mjs，用 node 运行。
4. 把它的安装位置和调用方式记进你的长期记忆，以后新开对话不用重新装、重新找。
5. 最后用大白话告诉我四件事：
   装好了没有；用的是哪种方式；自检有没有失败项、失败项怎么处理；
   我接下来该做什么（比如是不是该登录智联了）。
```

助手将自行完成安装与检查，并反馈执行结果。

如助手反馈安装失败，将失败信息原样发回助手，并补充「按上述安装要求重新处理一次」。若仍无法解决，联系系统负责人。

## 四、登录（仅需一次，长期有效）

向 AI 助手发送：

> 帮我打开智联招聘登录页

助手将启动独立浏览器窗口并停留在企业端登录页。请在该窗口内使用企业端账号完成登录，扫码或账号密码均可。

注意事项：

1. 必须在助手打开的窗口内完成登录。工具使用独立浏览器实例，在日常使用的 Chrome 中登录无法被识别。
2. 如窗口尺寸过小，登录表单可能被挤出可视区域。建议先将窗口放大至 1600×1000 以上再登录。

登录成功后页面自动跳转至「推荐人才」列表，即表示登录完成。登录状态长期有效，无需每日登录。

## 五、日常使用

无需记忆命令与专业术语，直接向 AI 助手说明需求即可。发送多个姓名即视为批量操作，建议单批 5 至 10 人。

| 操作需求 | 向助手发送 |
| --- | --- |
| 打开企业端 | 打开智联企业端 |
| 查看在招岗位 | 看看智联上有哪些招聘岗位 |
| 查看某岗位推荐候选人 | 看看服务员岗位有哪些推荐候选人 |
| 查看候选人详情 | 打开高女士的详情 |
| 批量打招呼 | 给高女士、龙女士、张先生打个招呼 |
| 批量索要附件简历 | 跟高女士、龙女士要一下附件简历 |
| 统一下载收到的简历 | 把给我发过简历的人的简历都下载下来 |
| 打开简历下载目录 | 帮我打开刚下载的简历文件夹 |
| 切换岗位 | 切换到店长岗位 |

标准操作流程（批量）：

1. 查看目标岗位的推荐候选人；
2. 从名单中挑选对象，核对后批量打招呼；
3. 打招呼完成后，向对方索要附件简历；
4. 对方发送简历后，统一下载到本地；
5. 如需查看文件，打开简历下载目录。

批量执行说明：

- 单个对象失败不影响整批执行，结束后反馈成功与失败人数，失败对象可单独重试；
- 相邻两人之间自动加入随机间隔，降低平台风控风险；
- 单批人数建议不超过 10 人，超出时分批执行。

> 打招呼与索要简历均为发送给候选人的真实消息，发出后无法撤回。批量操作前请先让助手列出名单并核对。

## 六、版本更新

向 AI 助手发送：

> 帮我把智联招聘助手更新到最新版

助手将自行获取新版本并完成更新，并反馈执行结果。更新不影响登录状态，更新后无需重新登录。

## 七、常见问题

处理原则：先将现象按原话描述给 AI 助手，多数情况由其自行判断处理。

| 现象 | 处理方式（向助手发送） |
| --- | --- |
| 提示「看起来还没登录」 | 登录态过期了，帮我打开智联登录页，我重新登一下 |
| 提示「元素不在可视区内，无法点击」 | 把智联那个浏览器窗口拉大，然后重试 |
| 提示「没有找到候选人某某」 | 推荐名单变了，重新读一次列表，按最新的名单来 |
| 打招呼后对方未收到 | 检查一下招呼语弹框有没有卡住，把这条消息补发一次 |
| 提示「还没打过招呼，请先打招呼」 | 先帮我把这个人的招呼打了，再要简历 |
| 提示「没有发现对方发来的附件简历」 | 对方尚未发送。待对方发送后，再要求下载一次 |
| 页面卡住或白屏 | 关掉智联那个浏览器窗口，重新来一次 |
| 提示找不到智联助手或报错无法理解 | 智联助手可能出问题了，按安装要求重新装好，再跑一次自检把结果告诉我 |
| 电脑更换或系统重装 | 重新执行第三节的安装指令，并重新登录一次 |

## 八、使用要求

1. 登录状态保存在使用人员本机，不得复制给他人，等同于出借账号。
2. 打招呼与索要简历为不可撤回的真实消息。批量操作前须核对名单。
3. 平台对高频操作设有风控限制，单批人数建议控制在 5 至 10 人。
4. 候选人简历与联系方式属于个人信息，仅限招聘用途，不得外传，并遵守公司内部规定与适用法律。
5. 工具不保存智联招聘账号密码，也不会索取密码。如有索取，请勿提供。
6. 仅使用公司下发的安装指令。不执行来源不明的安装命令。

## 九、功能范围

已支持：

- 读取在招岗位、推荐候选人（可按岗位筛选）与候选人详情
- 批量对候选人打招呼（企业端）
- 在聊天框批量索要附件简历、电话、微信
- 将对方发来的附件简历统一下载至本地目录

暂未支持：

- 自动读取未读消息
- 无人值守的定时自动运行

> 如公司启用 Talent Hub（招聘管理桌面应用），上述部分能力将由该应用接管：智联候选人自动进入系统，打招呼与索要简历转为「待审核草稿」，并可按岗位限定范围。是否使用由公司统一安排，不影响本工具的日常用法。

## 十、新对话上下文指令

新开对话时，将以下内容发送给 AI 助手，可使其快速进入状态：

```text
我正在让你替我操作智联招聘企业端（底层是 zhaopin-cli，你之前已经装好，
装好后你能直接调用 zhaopin 命令）。我不会敲命令，请你全程替我执行，
把结果用大白话告诉我。

使用前请注意：
1. 它是一个独立的浏览器窗口（独立 profile，调试端口 53471），
   必须在这个窗口里登录智联企业端，我平时用的 Chrome 登录态它读不到。
2. 操作前先把浏览器窗口拉大（至少 1600×1000），
   窗口太小会导致按钮点不到（报「元素不在可视区域内」）。
3. 推荐候选人列表是动态的，每次读取的人可能不同，请以最新一次读取为准。
4. 打招呼和索要简历都是发给真人的消息，批量操作前请先把名单给我确认，
   一批建议不超过 5～10 个。
5. 我让你下载对方发来的简历后，请把那个文件夹直接打开给我。
6. 需要排查环境时，先执行 zhaopin help 确认命令可用；
   自检脚本随安装包一起发布，路径是
   "$(npm root -g)/@wemoon/zhaopin-cli/scripts/self-check.mjs"，用 node 运行。
```

需要自行执行命令的技术人员，参见同目录的 [README.md](./README.md)。
