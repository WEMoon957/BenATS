# 智联招聘助手 · 使用说明（HR 版）

让 AI 助手替你在**智联招聘企业端**上「看候选人、打招呼、要简历」，你只需要动嘴。

> 这份文档写给不写代码的 HR。前面是安装（只做一次），后面是日常怎么用。

---

## 一、先搞清楚它是什么

它是装在**你自己电脑上**的一个小工具，配合桌面端 AI 助手使用。工作方式是：

1. 它会在你电脑上打开一个**独立的浏览器窗口**，连上智联招聘企业端；
2. 你用 AI 助手发指令（说人话就行），它代替你去点页面上的按钮；
3. **它不会替你登录**——账号密码/扫码必须你本人来；
4. **所有发出的消息（打招呼、要简历）都是你本人确认后才发的**。

**它是怎么操作页面的？** 全部用真实的鼠标点击、键盘输入和滚轮，不往页面里注入代码，也不修改智联页面的任何内容。

## 二、第一次使用：装好它（约 10 分钟，只做一次）

### 第 1 步：确认电脑有 Node.js（版本 20 以上）

打开「终端」（Mac）或「PowerShell」（Windows），输入：

```bash
node -v
```

- 显示 `v20.x.x` 或更高 → 已装好，跳到第 2 步；
- 提示「找不到命令」→ 去 <https://nodejs.org> 下载 **LTS 版**装上，装完重新打开终端再试一次。

### 第 2 步：确认电脑有 Chrome 或 Edge

一般电脑自带。没有的话装一个 Google Chrome 即可，**不用登录 Chrome 账号**。

### 第 3 步：装好这个助手

拿到 `zhaopin-cli` 文件夹后，**最省事的办法是直接让 AI 助手帮你装**。把下面这段话原样发给它：

```text
请帮我把 zhaopin-cli 装好：文件夹是 <这里是文件夹路径>。
请依次执行 npm install、npm run build，然后跑 node scripts/self-check.mjs 自检，
把自检结果告诉我，如果有不通过的项请一并说明怎么处理。
```

如果自检结果全是「[通过]」，就装好了。

> **万一自检报错**，最常见两种情况：
>
> - 提示浏览器启动失败 → 换一个**普通终端窗口**（不要用受限环境）重跑自检；
> - 提示找不到 Chrome → 把 Chrome 的安装路径告诉助手，让它用 `CHROME_PATH` 指定。

### 第 4 步：登录智联（只需一次，之后长期有效）

对 AI 助手说：

> 帮我打开智联招聘登录页

助手会弹出一个浏览器窗口，停在智联**企业端登录页**。请在那个窗口里用**企业端账号**完成登录（扫码或账号密码都行）。

> ⚠️ 两个容易踩的坑：
>
> 1. **必须在这个窗口里登录**。这个助手用的是它自己的独立浏览器，你在平时用的 Chrome 里登了，它**读不到**。
> 2. 窗口如果很小，登录表单会被挤到右边看不见，**先把窗口拉大**再登。

登录成功后，页面会自动跳到「推荐人才」列表，说明成功了。

## 三、日常怎么用（说人话就行）

**你不用记命令**，直接对 AI 助手说你要做什么。下面是最常用的说法：

| 你想做什么 | 就这样说 |
| --- | --- |
| 打开企业端 | 「打开智联企业端」 |
| 看有哪些在招岗位 | 「看看智联上有哪些岗位」 |
| 看某岗位的推荐候选人 | 「看看服务员岗位有哪些推荐候选人」 |
| 看某个人的详情 | 「打开高女士的详情」 |
| 打招呼 | 「给高女士打个招呼」 |
| 要简历 | 「跟李女士要一下附件简历」 |
| 换岗位 | 「切换到店长岗位」 |

**推荐的标准流程**：

```text
1. 「看看服务员岗位有哪些推荐候选人」
2. 挑好人 →「给高女士、龙女士打个招呼」
3. 打完招呼后 →「跟他们要一下附件简历」
4. 之后对方发来的简历，你去智联的「聊天」里看
```

> 💡 打断一下：**打招呼和要简历都是发给真人的消息，发出去撤不回**。助手在批量操作前应该先把名单给你确认。

## 四、如果你想自己敲命令

在 `zhaopin-cli` 文件夹里打开终端，可以这样用：

| 命令 | 作用 |
| --- | --- |
| `node dist/cli/index.js login` | 打开登录页 |
| `node dist/cli/index.js home` | 直接跳到企业端候选人推荐页 |
| `node dist/cli/index.js positions` | 列出在招岗位 |
| `node dist/cli/index.js recommend 服务员` | 切到「服务员」岗位并读推荐候选人 |
| `node dist/cli/index.js open 高女士` | 打开候选人详情 |
| `node dist/cli/index.js greet 高女士` | 打招呼 |
| `node dist/cli/index.js request 高女士 resume` | 索要附件简历 |

装过 `npm link` 的话，可以把开头的 `node dist/cli/index.js` 换成 `zhaopin`。

## 五、遇到问题怎么办

| 现象 | 原因与解决 |
| --- | --- |
| 提示「看起来还没登录」 | 登录态过期了，重新执行一次登录，**在助手弹出的那个窗口里**登 |
| 提示「元素不在可视区内，无法点击」 | 浏览器窗口太小了，**把窗口拉大再试一次** |
| 提示「没有找到候选人某某」 | 推荐列表是**动态变化**的，每次刷新的人可能不一样。先重新读一次列表，再按当前名字操作 |
| 打招呼后对方没收到 | 首次打招呼会弹「选择招呼语」对话框。如果对话框卡住没关，点一下里面的「发送」；建议勾选「设置为默认，不再弹出」 |
| 提示「还没打过招呼，请先打招呼」 | 要简历前必须先打过招呼，先去打招呼 |
| 页面卡住/白屏 | 关掉那个浏览器窗口，重新执行一次命令，助手会自动重开 |
| 完全跑不起来 | 对助手说「跑一下 zhaopin-cli 的自检，看哪里有问题」 |

## 六、几条要注意的事

1. **登录态存在你自己电脑上**（`~/.zhaopin-cli`），别把这个文件夹拷给别人，等于把账号借出去。
2. **消息发出去撤不回**。批量打招呼/要简历前，先让助手把名单列出来核对。
3. **别一口气打太多**。智联对频繁操作有风控，建议一批控制在 **5～10 个**，间隔着来。
4. **候选人信息是个人信息**。拿到的简历和联系方式只在招聘用途内使用，别外传，遵守公司内部规定和适用法律。
5. **账号安全**：这个工具不保存你的智联账号密码，也不需要你告诉它。如果它问你要密码，**别给**。

---

## 七、它能做什么、不能做什么

**现在能做**：

- 读取在招岗位、推荐候选人、候选人详情
- 打招呼（企业端）
- 在聊天框索要附件简历 / 电话 / 微信

**现在还不能做**：

- 自动下载对方发来的**附件简历**（需要你去智联「聊天」里手动下载）
- 自动读未读消息
- 无人值守定时自动运行

> 需要更强的自动化时，可以配合 Talent Hub 的「招聘接入」面板使用：那里能把智联候选人自动拉进系统做简历评分，也支持按岗位限定范围。

## 八、给 AI 助手的一段"上下文"（可选）

如果你希望助手更懂这套工具，可以把下面这段发给它：

```text
我正在使用 zhaopin-cli（本地智联招聘自动化工具，源码在 <路径>）。
使用前注意：
1. 它是一个独立的浏览器窗口（独立 profile，调试端口 53471），
   必须在这个窗口里登录智联企业端，我平时用的 Chrome 登录态它读不到。
2. 操作前先把浏览器窗口拉大（至少 1600×1000），
   窗口太小会导致按钮点不到（报「元素不在可视区域内」）。
3. 推荐候选人列表是动态的，每次读取的人可能不同，请以最新一次读取为准。
4. 打招呼和索要简历都是发给真人的消息，批量操作前请先把名单给我确认，
   一批建议不超过 5～10 个。
```
