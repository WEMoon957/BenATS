# 智联招聘助手 · 使用说明（HR 版）

让 AI 助手替你在**智联招聘企业端**上「看候选人、打招呼、要简历」，你只需要动嘴。

> 这份文档写给不写代码的 HR：从零装好（约 15 分钟，只做一次），到日常怎么用。
> 全程只需要「复制一段话 → 发给 AI 助手」。

---

## 一、先搞清楚它是什么

它由两部分组成，都装在**你自己电脑上**：

| 部分 | 是什么 | 谁提供 |
| --- | --- | --- |
| **WorkBuddy**（AI 助手） | 桌面 AI 助手，听得懂人话，能替你操作电脑 | 公司/负责人提供安装包 |
| **zhaopin-cli**（智联助手） | 一个小工具文件夹，教 WorkBuddy 怎么操作智联页面 | 从公司 GitHub 下载，免费公开 |

工作方式：

1. 它会在你电脑上打开一个**独立的浏览器窗口**，连上智联招聘企业端；
2. 你对 AI 助手发指令（说人话就行），它代替你去点页面上的按钮；
3. **它不会替你登录**——账号密码/扫码必须你本人来；
4. **所有发出的消息（打招呼、要简历）都是你本人确认后才发的**。

**它是怎么操作页面的？** 全部用真实的鼠标点击、键盘输入和滚轮，不往页面里注入代码，也不修改智联页面的任何内容。

---

## 二、准备工作（装之前确认三件事）

1. **电脑上装好了 WorkBuddy**。没装的话找负责人要安装包，先装它。
2. **电脑上有 Chrome 或 Edge 浏览器**。一般都自带；没有就装一个 Google Chrome，**不用登录 Chrome 账号**。
3. Node.js **不用单独装**——WorkBuddy 自带了运行环境。万一助手提示缺 Node，让它帮你装即可。

> 只需要满足前两条就可以开始了，第三条是给助手兜底的。

---

## 三、安装（只做一次，约 10 分钟）

打开 WorkBuddy，把下面这段话**原样复制**发给它：

```text
请帮我安装智联招聘助手 zhaopin-cli，按以下步骤执行：
1. 从 GitHub 下载开源仓库 https://github.com/WEMoon957/BenATS
   （直接下载 zip 压缩包并解压即可，不需要 GitHub 账号），
   把其中的 zhaopin-cli 文件夹放到一个固定位置，比如我的用户目录下；
2. 进入 zhaopin-cli 文件夹，执行 npm install；
   如果网络慢或超时，改用国内镜像源 https://registry.npmmirror.com 重试；
3. 执行 npm run build 完成构建；
4. 最后运行自检脚本 scripts/self-check.mjs，
   把自检结果逐项告诉我，有不通过的项请说明原因和处理办法。
注意：优先使用你自带的 Node 运行环境；如果没有可用的 Node，
请先帮我安装 Node.js 20 或更高版本再继续。
```

助手会自己下载、安装、构建，最后把**自检结果**贴给你。全部是「[通过]」就装好了。

> **万一有 [失败] 项**，最常见两种：
>
> - 「浏览器启动与 CDP 连接」失败 → 多半是运行环境有沙箱限制，让助手**换一种方式重跑**；还不行就按第五节的办法，用普通终端跑一次自检；
> - 「浏览器可执行文件」找不到 → 把你的 Chrome 安装路径告诉助手，让它用 `CHROME_PATH` 环境变量指定。

## 四、登录智联（只做一次，之后长期有效）

对 WorkBuddy 说：

> 帮我打开智联招聘登录页

助手会弹出一个浏览器窗口，停在智联**企业端登录页**。请在那个窗口里用**企业端账号**完成登录（扫码或账号密码都行）。

> ⚠️ 两个容易踩的坑：
>
> 1. **必须在这个窗口里登录**。这个助手用的是它自己的独立浏览器，你在平时用的 Chrome 里登了，它**读不到**。
> 2. 窗口如果很小，登录表单会被挤到右边看不见，**先把窗口拉大**再登。

登录成功后，页面会自动跳到「推荐人才」列表，说明成功了。登录一次长期有效，不用每天登。

## 五、日常怎么用（说人话就行）

**你不用记命令**，直接对 WorkBuddy 说你要做什么。**说几个人的名字就是批量操作**，一次 5～10 人最稳妥。最常用的说法：

| 你想做什么 | 就这样说 |
| --- | --- |
| 打开企业端 | 「打开智联企业端」 |
| 看有哪些在招岗位 | 「看看智联上有哪些岗位」 |
| 看某岗位的推荐候选人 | 「看看服务员岗位有哪些推荐候选人」 |
| 看某个人的详情 | 「打开高女士的详情」 |
| **批量打招呼** | 「给高女士、龙女士、张先生打个招呼」 |
| **批量要简历** | 「跟高女士、龙女士要一下附件简历」 |
| 换岗位 | 「切换到店长岗位」 |

**推荐的标准流程（批量版）**：

```text
1. 「看看服务员岗位有哪些推荐候选人」
2. 从名单里挑人 →「给高女士、龙女士、张先生打个招呼」
3. 打完招呼后 →「跟他们要一下附件简历」
4. 之后对方发来的简历，你去智联的「聊天」里看
```

批量执行时：

- **一个人失败不会中断整批**，最后会告诉你「成功几人、失败几人」，失败的单独再补一次就行；
- 两个人之间会自动随机停 1.5～3 秒，降低被平台风控的概率；
- **单批别超过 10 人**，人多就分几批说。

> 💡 **打招呼和要简历都是发给真人的消息，发出去撤不回**。批量操作前先让助手把名单列给你核对。

## 六、更新版本（偶尔做）

公司更新了工具后，对 WorkBuddy 说：

```text
请帮我更新 zhaopin-cli 到最新版：
重新从 https://github.com/WEMoon957/BenATS 下载 zip，解压后覆盖现有的
zhaopin-cli 文件夹（我的安装位置是 <你的路径>），然后在里面重新执行
npm install 和 npm run build。更新完告诉我结果。
```

**登录态不受更新影响**——它存在另一个地方（`~/.zhaopin-cli`），覆盖文件夹不会掉登录。

## 七、如果你想自己敲命令（可选）

一般用不上，让助手代跑就行。想自己跑时，在 `zhaopin-cli` 文件夹里打开终端：

| 命令 | 作用 |
| --- | --- |
| `bash scripts/run.sh login` | 打开登录页 |
| `bash scripts/run.sh positions` | 列出在招岗位 |
| `bash scripts/run.sh recommend 服务员` | 切到「服务员」岗位并读推荐候选人 |
| `bash scripts/run.sh open 高女士` | 打开候选人详情 |
| `bash scripts/run.sh greet 高女士 龙女士 张先生` | **批量打招呼**（三个名字一次跑完） |
| `bash scripts/run.sh request 高女士 龙女士 resume` | **批量要附件简历** |
| `bash scripts/run.sh request 高女士 resume phone` | 单人同时要简历和电话 |
| `bash scripts/run.sh self-check` | 运行自检 |

姓名之间用**空格、逗号或顿号**分隔都行，比如 `greet 高女士、龙女士` 和 `greet 高女士 龙女士` 等价。批量跑完最后一行会汇总「共几人、成功几人、失败几人」，有失败时命令以错误状态退出，方便发现漏网的人。

`run.sh` 会自动找到电脑上可用的 Node（包括 WorkBuddy 自带的），所以即使终端里敲 `node` 提示「找不到命令」也不影响。装过 `npm link` 的话，也可以把命令开头的 `bash scripts/run.sh` 换成 `zhaopin`，例如 `zhaopin greet 高女士 龙女士`。

## 八、遇到问题怎么办

| 现象 | 原因与解决 |
| --- | --- |
| 提示「看起来还没登录」 | 登录态过期了，重新执行一次登录，**在助手弹出的那个窗口里**登 |
| 提示「元素不在可视区内，无法点击」 | 浏览器窗口太小了，**把窗口拉大再试一次** |
| 提示「没有找到候选人某某」 | 推荐列表是**动态变化**的，每次刷新的人可能不一样。先重新读一次列表，再按当前名字操作 |
| 打招呼后对方没收到 | 首次打招呼会弹「选择招呼语」对话框。如果对话框卡住没关，点一下里面的「发送」；建议勾选「设置为默认，不再弹出」 |
| 提示「还没打过招呼，请先打招呼」 | 要简历前必须先打过招呼，先去打招呼 |
| 页面卡住/白屏 | 关掉那个浏览器窗口，重新执行一次命令，助手会自动重开 |
| 完全跑不起来 | 对助手说「跑一下 zhaopin-cli 的自检，看哪里有问题」 |
| 电脑换了/重装了 | 把第三节那段安装话术再发一遍，装完后重新登录一次 |

## 九、几条要注意的事

1. **登录态存在你自己电脑上**（`~/.zhaopin-cli`），别把这个文件夹拷给别人，等于把账号借出去。
2. **消息发出去撤不回**。批量打招呼/要简历前，先让助手把名单列出来核对。
3. **别一口气打太多**。智联对频繁操作有风控，建议一批控制在 **5～10 个**，间隔着来。
4. **候选人信息是个人信息**。拿到的简历和联系方式只在招聘用途内使用，别外传，遵守公司内部规定和适用法律。
5. **账号安全**：这个工具不保存你的智联账号密码，也不需要你告诉它。如果它问你要密码，**别给**。

## 十、它能做什么、不能做什么

**现在能做**：

- 读取在招岗位、推荐候选人（可按岗位筛选）、候选人详情
- **批量**对候选人打招呼（企业端）
- **批量**在聊天框索要附件简历 / 电话 / 微信

**现在还不能做**：

- 自动下载对方发来的**附件简历**（需要你去智联「聊天」里手动下载）
- 自动读未读消息
- 无人值守定时自动运行

> 公司如果启用了 **Talent Hub**（招聘管理桌面应用），上述部分能力会由它接管：智联候选人自动进入系统、打招呼与索要简历变成「待审核草稿」、可按岗位限定范围。是否使用由公司统一安排，不影响本工具的日常用法。

```text

使用前注意：

   必须在这个窗口里登录智联企业端，我平时用的 Chrome 登录态它读不到。

   一批建议不超过 5～10 个。
```
