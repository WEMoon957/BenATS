# 智联招聘助手 · 使用说明（HR 版）

让 AI 助手或一行命令替你在**智联招聘企业端**上「看候选人、打招呼、要简历」，你只需要动嘴或敲一条命令。

> 这份文档写给不写代码的 HR：从零装好（约 10 分钟，只做一次），到日常怎么用。  
> 装法三选一——会敲命令的走[方式 A](#方式-a一条-npm-命令推荐最省事)，不想碰命令行的走[方式 C](#方式-c交给-workbuddy-代装完全不用敲命令)。
>
> 三条路装完的结果完全一样：**电脑上多一条 `zhaopin` 全局命令，在任何目录都能直接用。**

---

## 一、先搞清楚它是什么

它由两部分组成，都装在**你自己电脑上**：

| 部分 | 是什么 | 谁提供 |
| --- | --- | --- |
| **智联助手**（`zhaopin-cli`） | 一个命令行小工具，装完电脑上就多一条 `zhaopin` **全局命令** | 公司提供（npm 包或安装包），免费 |
| **WorkBuddy**（AI 助手） | 桌面 AI 助手，听得懂人话，能替你敲命令、操作电脑 | 公司/负责人提供，**选装** |

工作方式：

1. 它会在你电脑上打开一个**独立的浏览器窗口**，连上智联招聘企业端；
2. 你发指令（说人话或敲命令都行），它代替你去点页面上的按钮；
3. **它不会替你登录**——账号密码/扫码必须你本人来；
4. **所有发出的消息（打招呼、要简历）都是你本人确认后才发的**。

**它是怎么操作页面的？** 全部用真实的鼠标点击、键盘输入和滚轮，不往页面里注入代码，也不修改智联页面的任何内容。

## 二、准备工作（装之前确认三件事）

1. **电脑上有 Chrome 或 Edge 浏览器**。一般都自带；没有就装一个 Google Chrome，**不用登录 Chrome 账号**。
2. **电脑上有 Node.js 20 或更高版本**。走方式 A 必须有；走方式 B 可以让 WorkBuddy 代装，跳过这条。
3. **（可选）装好 WorkBuddy**。没有它也能用，只是所有操作都要你自己敲命令。

**怎么装 Node.js**：打开 [nodejs.org/zh-cn](https://nodejs.org/zh-cn)，下载 LTS 版本安装包，一路点「下一步」即可。装完打开终端（macOS：聚焦搜索里输 `终端` 或 `Terminal`；Windows：开始菜单搜 `PowerShell`），输入：

```bash
node -v
```

显示 `v20` 以上的版本号就算好了。

## 三、安装（只做一次，约 10 分钟）

三条路任选一条，**装完结果都一样**：电脑上多出一条全局命令 `zhaopin`，在**任何目录**的终端里都能直接用。

### 方式 A：一条 npm 命令（推荐，最省事）

打开终端（macOS 的「终端」或 Windows 的「PowerShell」），把下面这条命令**原样粘贴**进去回车：

```bash
npm install -g @joohw/zhaopin-cli@latest
```

看到 `added xx packages` 之类的提示就装完了。

> - **网络慢或超时**：加上国内镜像源重跑一次：`npm install -g @joohw/zhaopin-cli@latest --registry=https://registry.npmmirror.com`
> - **提示 `404 Not Found`**：说明公司还没把工具发布到 npm，改用方式 B 或方式 C。
> - **macOS 提示没有权限（`EACCES` / `permission denied`）**：见[第八节](#八遇到问题怎么办)的「npm 权限一次性设置」，只需做一次。

### 方式 B：下载源码后装成全局命令（不依赖 npm 发布）

1. 下载开源仓库的 zip 并解压（不需要 GitHub 账号）：<https://github.com/WEMoon957/BenATS>
2. 把解压出来的 `zhaopin-cli` 文件夹放到一个**固定位置**（比如「文稿」目录下），不要留在下载文件夹里。
3. 打开终端，进入这个文件夹，依次执行两条命令：

```bash
cd <你放 zhaopin-cli 的文件夹路径>
npm install          # 装依赖，并自动完成构建
npm install -g .     # 注册成全局命令
```

> 第 3 步的 `npm install -g .` 才是让命令**全局可用**的关键，漏掉它就只能在这个文件夹里跑。

### 方式 C：交给 WorkBuddy 代装（完全不用敲命令）

打开 WorkBuddy，把下面这段话**原样复制**发给它：

```text
请帮我把智联招聘助手（zhaopin-cli）装成全局命令行工具，
装完后我要在任何目录的终端里都能直接用 zhaopin 命令。按以下步骤执行：
1. 检查本机是否有 Node.js 20 或更高版本；没有就用你自带的 Node 运行环境，
   或先帮我安装 Node.js 20 以上版本。
2. 先试 npm install -g @joohw/zhaopin-cli@latest；
   如果提示 404 说明还没发布到 npm，改用源码方式：
   下载 https://github.com/WEMoon957/BenATS 的 zip 并解压，
   把 zhaopin-cli 文件夹放到一个固定位置，进入该文件夹执行
   npm install，再执行 npm install -g . 注册全局命令。
3. 网络慢或超时就用国内镜像源 https://registry.npmmirror.com 重试。
4. 关键一步：验证全局可用。切换到一个不是 zhaopin-cli 的目录
   （比如我的用户目录），执行 zhaopin help。
   如果提示找不到 zhaopin 或找不到 node，
   帮我把 npm 全局目录和 node 加进 PATH，重开终端后再验证一次，
   并告诉我以后该怎么运行 zhaopin 命令。
5. 最后跑一次自检并把结果逐项告诉我：
   npm 包内路径是 "$(npm root -g)/@joohw/zhaopin-cli/scripts/self-check.mjs"，
   源码方式则是 zhaopin-cli/scripts/self-check.mjs，用 node 运行。
   有失败的项请说明原因和处理办法。
```

### 三条路都要做：确认「全局可用」

不管走哪条路，装完都在**任意目录**（不要在 `zhaopin-cli` 文件夹里）执行一次：

```bash
zhaopin help
```

列出 `login` / `positions` / `recommend` / `greet` / `request` 等命令，才算真正装好——这一步验的是「全局可用」，不是「文件装没装上」。

> **装完想更稳妥地体检一次**，对 WorkBuddy 说「跑一下 zhaopin 的自检」。它会逐项检查 Node 版本、浏览器、数据目录、智联域名可达性和浏览器能否启动。

## 四、登录智联（只做一次，之后长期有效）

在终端执行：

```bash
zhaopin login
```

（用 WorkBuddy 的话，也可以直接说「帮我打开智联招聘登录页」。）

助手会弹出一个浏览器窗口，停在智联**企业端登录页**。请在那个窗口里用**企业端账号**完成登录（扫码或账号密码都行）。

> ⚠️ 两个容易踩的坑：
>
> 1. **必须在这个窗口里登录**。这个助手用的是它自己的独立浏览器，你在平时用的 Chrome 里登了，它**读不到**。
> 2. 窗口如果很小，登录表单会被挤到右边看不见，**先把窗口拉大**再登。

登录成功后，页面会自动跳到「推荐人才」列表，说明成功了。登录一次长期有效，不用每天登。

## 五、日常怎么用（说人话就行）

**你不用记命令**，直接对 WorkBuddy 说你要做什么。**说几个人的名字就是批量操作**，一次 5～10 人最稳妥。最常用的说法：

| 你想做什么 | 就这样说 |
| --- | --- |
| 打开企业端 | 「打开智联企业端」 |
| 看有哪些在招岗位 | 「看看智联上有哪些岗位」 |
| 看某岗位的推荐候选人 | 「看看服务员岗位有哪些推荐候选人」 |
| 看某个人的详情 | 「打开高女士的详情」 |
| **批量打招呼** | 「给高女士、龙女士、张先生打个招呼」 |
| **批量要简历** | 「跟高女士、龙女士要一下附件简历」 |
| **统一下载收到的简历** | 「把发过我简历的人的简历都下载下来」 |
| 换岗位 | 「切换到店长岗位」 |

**推荐的标准流程（批量版）**：

```text
1. 「看看服务员岗位有哪些推荐候选人」
2. 从名单里挑人 →「给高女士、龙女士、张先生打个招呼」
3. 打完招呼后 →「跟他们要一下附件简历」
4. 对方发来简历后 →「把发过我简历的人的简历都下载下来」
5. 下载好的简历在电脑的 ~/.zhaopin-cli/downloads 文件夹里
```

批量执行时：

- **一个人失败不会中断整批**，最后会告诉你「成功几人、失败几人」，失败的单独再补一次就行；
- 两个人之间会自动随机停 1.5～3 秒，降低被平台风控的概率；
- **单批别超过 20人**，人多就分几批说。

> 💡 **打招呼和要简历都是发给真人的消息，发出去撤不回**。批量操作前先让助手把名单列给你核对。

## 六、更新版本（偶尔做）

**用方式 A 或方式 C 装的**：再跑一次同样的安装命令就会升级到最新版：

```bash
npm install -g @joohw/zhaopin-cli@latest
```

**用方式 B 装的**（源码放在固定文件夹里）：重新下载最新的 zip，覆盖原来那个 `zhaopin-cli` 文件夹，然后在文件夹里重跑两条命令：

```bash
cd <你放 zhaopin-cli 的文件夹路径>
npm install          # 重新装依赖并构建
npm install -g .     # 重新注册全局命令
```

用 WorkBuddy 的话，直接说「帮我把 zhaopin-cli 更新到最新版」即可。

**登录态不受更新影响**——它存在另一个地方（`~/.zhaopin-cli`），升级不需要重新登录。

## 七、如果你想自己敲命令（可选）

一般用不上，让助手代跑就行。自己敲时命令都以 `zhaopin` 开头：

| 命令 | 作用 |
| --- | --- |
| `zhaopin help` | 查看所有可用命令 |
| `zhaopin login` | 打开登录页 |
| `zhaopin positions` | 列出在招岗位 |
| `zhaopin recommend 服务员` | 切到「服务员」岗位并读推荐候选人 |
| `zhaopin open 高女士` | 打开候选人详情 |
| `zhaopin greet 高女士 龙女士 张先生` | **批量打招呼**（三个名字一次跑完） |
| `zhaopin request 高女士 龙女士 resume` | **批量要附件简历** |
| `zhaopin request 高女士 resume phone` | 单人同时要简历和电话 |
| `zhaopin download 高女士 龙女士` | **批量下载**指定人发来的附件简历 |
| `zhaopin download-all` | **统一下载**：扫描全部会话，把收到的附件简历都存到本地 |

姓名之间用**空格、逗号或顿号**分隔都行，比如 `zhaopin greet 高女士、龙女士` 和 `zhaopin greet 高女士 龙女士` 等价。批量跑完最后一行会汇总「共几人、成功几人、失败几人」，有失败时命令会报错退出，方便发现漏网的人。

下载的简历统一放在 `~/.zhaopin-cli/downloads/` 文件夹里，文件名带候选人姓名；同一个人重复跑不会重复下载。要重新下载某个人，删掉那个文件再跑一次即可。

## 八、遇到问题怎么办

先跑一次 `zhaopin help`，能列出命令列表就说明工具本身没问题，再看下表：

| 现象 | 原因与解决 |
| --- | --- |
| 提示「看起来还没登录」 | 登录态过期了，重新执行一次 `zhaopin login`，**在助手弹出的那个窗口里**登 |
| 提示「元素不在可视区内，无法点击」 | 浏览器窗口太小了，**把窗口拉大再试一次** |
| 提示「没有找到候选人某某」 | 推荐列表是**动态变化**的，每次刷新的人可能不一样。先重新读一次列表，再按当前名字操作 |
| 打招呼后对方没收到 | 首次打招呼会弹「选择招呼语」对话框。如果对话框卡住没关，点一下里面的「发送」；建议勾选「设置为默认，不再弹出」 |
| 提示「还没打过招呼，请先打招呼」 | 要简历前必须先打过招呼，先去打招呼 |
| 提示「没有发现对方发来的附件简历」 | 对方还没发简历过来（状态是「附件简历索要中」就是还在等对方），等对方发了再下载 |
| 页面卡住/白屏 | 关掉那个浏览器窗口，重新执行一次命令，助手会自动重开 |
| 安装时提示 `404 Not Found` | 工具还没发布到 npm，改用[方式 B](#方式-b下载源码后装成全局命令不依赖-npm-发布)或[方式 C](#方式-c交给-workbuddy-代装完全不用敲命令) |
| 刚发布当天装不上、提示找不到包 | 国内镜像站还没同步最新版本。去掉 `--registry=https://registry.npmmirror.com`，用官方源装一次，或过几小时再试 |
| 安装时报 `EACCES` / `permission denied` | 全局目录没写权限，按下面的「让 zhaopin 全局可用」处理 |
| 提示 `command not found: zhaopin` | 命令装上了，但所在的目录**不在 PATH 里**，按下面的「让 zhaopin 全局可用」处理 |
| 提示 `env: node: No such file or directory` | `node` 不在 PATH 里，按下面的「让 Node 也在 PATH 里」处理 |
| 提示 `command not found: node` 或 `npm` | 还没装 Node.js，回到[第二节](#二准备工作装之前确认三件事)装一个 Node 20 以上版本，然后重开终端 |
| 完全跑不起来 | 对助手说「跑一下 zhaopin 的自检，看哪里有问题」 |

### 让 zhaopin 全局可用（macOS / Linux）

先查 npm 把命令装到哪了：

```bash
npm prefix -g
```

输出的路径就是全局目录，`zhaopin` 命令实际在 `<该路径>/bin/` 里。常见两种情况：

**情况一：路径是 `/usr/local` 之类系统目录。** 当前账户没写权限，安装就会报 `EACCES`。把全局目录挪到自己的用户目录，做一次就够：

```bash
mkdir -p ~/.npm-global
npm config set prefix ~/.npm-global
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.zshrc
source ~/.zshrc
```

（用 bash 的把 `~/.zshrc` 换成 `~/.bash_profile`。Windows 一般不需要这一步。）

**情况二：路径看着正常，但终端里就是找不到 `zhaopin`。** 把这个 bin 目录加进 PATH：

```bash
echo 'export PATH="<上面查到的路径>/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

改完**重新执行一遍安装命令**，再验证：

```bash
npm install -g @joohw/zhaopin-cli@latest
cd ~ && zhaopin help
```

> `cd ~` 是故意加的：在 `zhaopin-cli` 文件夹里能跑，不代表全局可用。

### 让 Node 也在 PATH 里

`zhaopin` 内部要调用 `node`。提示 `env: node: No such file or directory` 就说明 `node` 没在 PATH 里（用 WorkBuddy 自带 Node 装的时候最常见）。两种办法，任选一种：

- 最省事：对 WorkBuddy 说「帮我把 node 加进 PATH，让 zhaopin 在我自己的终端里能用」；
- 或者到 [nodejs.org/zh-cn](https://nodejs.org/zh-cn) 自己装一次 Node 20 以上版本，然后重开终端。

**实在不想折腾 PATH**：让 WorkBuddy 代跑即可，它知道工具和 Node 都在哪里。

## 九、几条要注意的事

1. **登录态存在你自己电脑上**（`~/.zhaopin-cli`），别把这个文件夹拷给别人，等于把账号借出去。
2. **消息发出去撤不回**。批量打招呼/要简历前，先让助手把名单列出来核对。
3. **别一口气打太多**。智联对频繁操作有风控，建议一批控制在 **5～10 个**，间隔着来。
4. **候选人信息是个人信息**。拿到的简历和联系方式只在招聘用途内使用，别外传，遵守公司内部规定和适用法律。
5. **账号安全**：这个工具不保存你的智联账号密码，也不需要你告诉它。如果它问你要密码，**别给**。
6. **只从官方渠道装**。认准包名 `@joohw/zhaopin-cli`；别的名字来源不明的包不要装。

## 十、它能做什么、不能做什么

**现在能做**：

- 读取在招岗位、推荐候选人（可按岗位筛选）、候选人详情
- **批量**对候选人打招呼（企业端）
- **批量**在聊天框索要附件简历 / 电话 / 微信
- **统一下载**对方发来的附件简历到本地文件夹（`~/.zhaopin-cli/downloads/`）

**现在还不能做**：

- 自动读未读消息
- 无人值守定时自动运行

> 公司如果启用了 **Talent Hub**（招聘管理桌面应用），上述部分能力会由它接管：智联候选人自动进入系统、打招呼与索要简历变成「待审核草稿」、可按岗位限定范围。是否使用由公司统一安排，不影响本工具的日常用法。

## 十一、给 AI 助手的一段"上下文"（推荐保存）
